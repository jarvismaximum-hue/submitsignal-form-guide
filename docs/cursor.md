# Cursor preparation

This is an Agent Plugins standard package: root plugin.json, mcp.json and skills.
It contains no variable expansion, local executable or private app binding.

Use Cursor's documented local plugin directory or Import from Disk only in an
authorized existing Cursor installation. Confirm the exact skill and three tools
load, then run the shared five positive and three negative review cases. A generic
MCP call or Codex run does not verify Cursor's package loading.

Public route: https://cursor.com/marketplace/publish. It requires a public Git
repository, an open source license and local testing. MIT is included for these
guide materials. Public guide source: https://github.com/jarvismaximum-hue/submitsignal-form-guide.
Source publication is complete; Cursor marketplace submission and actual host checks remain unverified.
