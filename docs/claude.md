# Claude preparation

For an existing signed-in Claude Code installation, load this exact folder for one
session with `claude --plugin-dir /absolute/path/to/submitsignal-form-guide`.
Do not add it globally to conduct a temporary review. Check all five positive and
three negative cases, preserving the actual tool calls and results.

For the hosted Claude connector, an authorized user can add the public endpoint
as a custom connector. This does not verify the plugin bundle or list it publicly.

Public directory route: https://claude.ai/directory/manage. The connector submission
uses the remote URL. A bundle submission needs a GitHub repository, public before
listing and a README. The approved MIT license is included. Submit the server as a connector and the
bundle from the same intended publisher organization. Current local syntax checks
cannot establish paid-plan access, organization authority, review or publication.
